## Curiosidades sobre o Git

- O nome **Git** foi escolhido por Linus Torvalds, criador do Linux. A palavra pode ser interpretada de forma humorística como "pessoa desagradável" em inglês.
- O Git foi criado em 2005 para gerir o desenvolvimento do kernel Linux.
- O Git é um sistema de controlo de versões distribuído: cada clone contém o histórico completo do projeto.
- Os branches no Git são apenas referências leves para commits, por isso são rápidos de criar e alternar.
- Um commit no Git é identificado por um hash, que funciona como uma impressão digital do seu conteúdo e histórico.
- O Git consegue trabalhar offline. É possível criar commits, consultar o histórico e criar branches sem ligação à internet.
